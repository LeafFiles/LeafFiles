# LeafFiles 2.5.2

版本 2.5.2，构建号 29。本次更新重点修复空间清理卡住的问题，并完善文件操作反馈。

- 修复清理后更新目录占用时，缺少目录统计项可能导致的无限循环；优化批量清理期间的文件占用检查。
- 通用清理、软件清理和微信附件清理在当前页面展示进度和停止按钮。清理结果在页面内显示，扫描详情、忽略列表和历史记录按需查看。
- 压缩和解压增加进度反馈；批量删除展示进度并可停止后续项目。停止不会自动恢复已移入废纸篓的文件。
- 增加旧版文件剪贴板格式兼容，调整 UU 远程文件占位符的接收处理；不同设备和 UU 远程版本上的跨设备传输仍需进一步验证。
- 精简侧边栏底部入口，保留设置入口。

## English

LeafFiles 2.5.2 (build 29) fixes a possible infinite loop while updating storage statistics after cleanup and improves open-file checks for large batches. Cleanup now displays progress and a stop control within the page, followed by inline results and on-demand details. Archive operations provide progress feedback, and batch deletion can be stopped between items. File clipboard compatibility and UU Remote placeholder handling have been improved; real-device UU Remote transfers still need further verification. The bottom of the sidebar is simpler.
