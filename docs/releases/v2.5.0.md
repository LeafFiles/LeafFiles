# LeafFiles 2.5.0

版本 2.5.0，构建号 27。

- 重新设计空间清理：按类别显示扫描结果和占用，选择类别查看对应文件；窄窗口保留筛选入口。微信附件和网盘下载文件在发现对应候选后显示。
- 精简通用清理和软件清理操作，扫描设置改为独立弹窗；扫描范围、保留时间或目录更改后提示重新扫描，避免使用过期结果清理。
- 设置窗口与分类扫描设置采用侧边导航和分组布局；各类别仍支持独立配置多个路径及结果上限。
- 优化路径栏过长时的折叠显示，保留输入路径的入口。
- 更新仓库与官网地址，旧地址及安装命令继续兼容。

清理候选默认不选中；请确认后再移到废纸篓。目录访问受 macOS 权限限制。

## English

LeafFiles 2.5.0 (build 27) refreshes storage cleanup with category summaries and a file list, simplifies software cleanup and scan settings, and reorganizes application and category settings. Changing scan settings requires a rescan before cleanup. The path bar handles long paths more clearly. The repository and website links have moved while the previous install command remains compatible.
