# LeafFiles 2.5.1

版本 2.5.1，构建号 28。

- 设置改为应用内完整页面，可通过左侧栏、菜单或 ⌘, 打开，浏览侧栏、详情栏和页签暂时隐藏。
- 点击返回可恢复进入设置之前的页面，保留已有页签、分屏以及侧栏展开状态；设置页中 ⌘W 也可返回。
- 设置页标题栏与主页保持相同高度，标题靠左，返回区域更简洁；设置项目继续按类别导航。
- 感谢 [@KaKi87](https://github.com/KaKi87) 在 [Issue #7](https://github.com/LeafFiles/LeafFiles/issues/7) 提出在应用内打开设置的建议。

## English

LeafFiles 2.5.1 (build 28) brings Settings into the main window. Open it from the sidebar, application menu or ⌘,; returning preserves the previous page, tabs, split view and sidebar state. The settings header now matches the main window and has a simpler back control.

Thanks to [@KaKi87](https://github.com/KaKi87) for suggesting in-app settings in [Issue #7](https://github.com/LeafFiles/LeafFiles/issues/7).
