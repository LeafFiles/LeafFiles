# LeafFiles 2.6.0

版本 2.6.0，构建号 30。适用于 macOS 13 及更新版本，安装包同时支持 Apple 芯片和 Intel。

- **框选与批量操作**：列表和图标视图支持从空白处拖动框选，靠近边缘时自动滚动。修复列表首行可能被卷到表头下面的问题，并减少图标视图拖选时的刷新开销。图标视图支持方向键和 Shift 扩选，也可一起拖动已选文件。拖放会提示目标位置；多选后可按 Delete 或 ⌘⌫ 移到废纸篓。
- **打开方式**：没有默认应用时，直接在 LeafFiles 内选择。支持搜索已安装的应用或输入其他应用的路径，可按扩展名记住选择，访达的关联设置保持原样。
- **预览与解压**：右侧详细信息区可以预览本地文件、浏览文件夹并预览其中的文件。压缩包预览可将选中的文件或文件夹提取到指定位置。同名文件会保留，提取需为整包临时解压预留磁盘空间。
- **图片与 PDF**：可旋转、等比调整图片尺寸并导出 PNG、JPEG 或 TIFF。PDF 可合并、按页提取或旋转。处理生成新文件，原件保留。
- **重命名与文本**：批量重命名增加前缀、替换和编号示例。支持从内置或自定义模板新建文件，以及在 LeafFiles 内编辑纯文本。保存时检查原文件是否已被外部修改，发生冲突时可另存副本。

## English

LeafFiles 2.6.0 (build 30) supports macOS 13 and later on Apple silicon and Intel Macs.

- **Selection and drag and drop:** Drag from empty space to select files in list and icon views. Edge scrolling keeps the first row clear of the header, and icon highlights follow the pointer more responsively. Use arrow keys and Shift in icon view, drag selected icons as a group, or press Delete or Command–Delete to move selected items to the Trash.
- **Open With:** Choose an application inside LeafFiles when a file has no default. Search installed apps or enter an application path, then remember the choice by extension without changing Finder associations.
- **Previews and archives:** Preview local files and browse folder contents in the inspector. Extract selected archive members into a folder of your choice. Existing files are preserved, and extraction requires space for temporary staging of the entire archive.
- **Images and PDFs:** Rotate or resize images and export PNG, JPEG or TIFF. Merge, extract or rotate PDF pages. These operations save new files.
- **Renaming and text:** Apply example rules in Batch Rename, create files from built-in or custom templates, and edit plain text. The editor detects changes to the file on disk and lets you save a copy.
